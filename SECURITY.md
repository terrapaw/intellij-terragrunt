# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this plugin, please report it privately using GitHub's [private vulnerability reporting](https://github.com/terrapaw/intellij-terragrunt/security/advisories/new).

Please do **not** open a public issue for security vulnerabilities.

## Supported Versions

| Version | Supported |
| ------- | --------- |
| Latest  | ✅        |
| Older   | ❌        |

Only the latest release receives security fixes.
